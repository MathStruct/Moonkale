This page is the single place for “where are we”. The landing page, Home, the README and the Roadmap link here instead of repeating it. Update it at the end of every milestone. Checked against the code on 2026-10-01 (refactor branch = master + Milestone 17).

Legend: ✅ built and tested · ◐ partly built (the missing part is named) · 📝 designed only, no code · ⚠ built but broken

Numbers

40 crates · 46 900 lines of Rust · ~1 000 lines of TypeScript in four view bundles · 146 Rust tests · 47 browser suites (Playwright) · CI since 2026-10-01: fmt, layering rules, tests, clippy, wasm check, six browser suites (R-39) · releases YYMMDD-proto for Arch, Debian, Nix, tarball, Windows, macOS, Android (Install).

Security CI (WP-47, checked 2026-10-17)

Blocking all-feature Rust licence/source/advisory checks, cargo-audit, six JS lockfile audits and offline SHA-256 checks for 63 vendored files are implemented. Existing Rust/npm findings are dated exceptions, awaiting Daniel’s upgrade choices; they are not fixed. Two separate non-blocking nightly parser fuzz jobs run for 60 seconds each. Local runs completed 2,140,753 math and 8,218,925 flow inputs without crashes; 18 parser tests and nine gate regression tests pass. The first CI math crash (P-212) now has source-preserving production guards and four corpus regressions; 216 code-view and five agent unit tests pass (code-view uses the supported DOCS_RS=1 registry-write bypass); browser verification remains due. The math normaliser remains planned; the target covers today’s math range parser. See Security and How to Write Tests for scope and commands. The page’s older whole-product inventory date above is unchanged; this paragraph checks only WP-47, not every area below.

Portable CI (WP-26, checked 2026-10-17)

Windows and Apple-silicon macOS now have an advisory portable matrix for core, folder, index, extension API, LLM, Unison and remote library tests, followed by the default extension distribution check. Native runs are pending GitHub validation; UI, installers and Intel macOS are outside this CI job. See How to Write Tests.

First Windows UI findings (P-217–P-219, checked 2026-10-22)

Responsive layout changes retain each desktop tab group’s selection and ignore viewports smaller than 100 pixels on either axis. Rich Markdown images resolve through the document’s source and retain relative paths when saved. CodeMirror find/replace uses theme tokens and English/German/Chinese locale phrases. VirtualDom and browser regressions cover these changes, with packaged Linux/WebKit private-display checks of Graph retention, Rich images and the German find bar. Windows recheck remains Daniel’s. See Problem Log, Markdown and Typst Editor and Code Editor.

Canvas components (WP-04/05, checked 2026-10-23)

The engine reports one changed camera mapping per frame and accepts embedded rectangles without label/symbol ink. A shared Dioxus canvas-layer crate mounts world-space cards over the two canvas surfaces, culls small/off-screen/3D cards, and isolates component clicks. Flow’s parameter editor uses it, follows the camera and offers header dragging with one undo step. Automatic flow fits leave room for the card; explicit zoom remains free. Extension-provided node-kind views remain planned. See the Components on the canvas entry in Specifications.

E-graph drawing (WP-07, checked 2026-10-23)

The Graph panel’s paste dialog accepts plain engine e-graph JSON: e-classes as anchor-backed groups, operators with child edges to classes, and labelled rewrite provenance. Per-class/all-class collapse and expand use existing aggregate/proxy deltas. Provenance can be hidden; selecting an operator highlights incoming rewrite ancestry. The synthetic (a*2)/2 → a fixture and engine/panel browser suites cover this path. Input is an in-memory bounded snapshot; JSON file opening, editing and live Sophia production remain open. See Graph View and North Star for the producer contract.

Coarse graph queries and navigation (WP-06, checked 2026-10-23)

Hierarchy sources expose bounded coarse cuts, counts, weighted relations and region members. The graph toolbar chooses a tier at open/Reload, shows it and offers a per-source override. One region expands/collapses through the existing aggregate delta path, with pinned context and a stable camera. Core’s fully generated million-node native projection takes about 1.32 seconds; the separate lazy million-node browser fixture checks the production panel. Sophia copy queries take 3.68 s cold / 1.81–1.83 s warm for 199,257 nodes → 2; cached source cuts/layouts, upstream full traversal, nested navigation and persistent workspace overrides remain open. See Case Selector and Graph View.

Flow symbols and typed cells (WP-11/15, checked 2026-10-23)

Closed absolute symbol subpaths fill in block colour. Flow grid settings govern insertion, Layout and dragging, including card headers; Alt bypasses snapping. Core now models UTC date/time cells, labelled node references and bounded finite vectors. SQL date metadata and DuckDB numeric lists feed localized date display and theme-coloured sparklines; index search paths carry node references. Unit/source/grid tests and the flow/SQL browser suites pass, including real MTK/RxInfer simulations, fill pixels, saved grid positions, locales and reference activation. Both parsers have bounded fuzz targets. See Flow Editor and Table Editor for conversion limits.

Content identity nesting (SR-145, checked 2026-10-24)

Content-id syntax, binding and scope passes use explicit heap stacks with total byte/work budgets, replacing the depth-128 refusal. Normalizer v7 and golden ids remain unchanged. Julia’s modules_around and locate helpers are exported for Sophia. See packages/services/content-id/content-id.md for limits and checks.

Shared code naming (WP-21 prerequisite, checked 2026-10-23)

moonkale-content-id now exposes shared binding/entity-path metadata and method grouping for Julia, Rust and Python. Julia ownership is ported from Sophia 773d9898; Rust impl/trait paths and Python class paths use caller-supplied root context. Unknown roots are flagged, invalid names reported, and naming golden data complements the unchanged v7 identity fixtures. The default-off per-folder Sophia writer is implemented (WP-21, 2026-10-24): manifest-hash reuse, atomic watcher batches, bounded conflict retries and a read-only additional Source with current-file fallback on stale text. Definition ids rebuild from files; generic nominal ids may change on rebuild. See Code Graph Schema and Work Packages.

Sophia folder cache (WP-21, checked 2026-10-24)

Default-off sophia writes admitted Rust/Julia/Python code into the derived .moonkale/code.sophia cache and opens it as an additional read-only Source. Reopen skips unchanged files; one watcher window is one transactional batch, including moves and bounded name-owner retries. Stale reads fall back to current files. Ten hermetic folder-store regressions and four browser suites pass; all 18 mandatory/feature gate commands pass (826 workspace tests, seven ignored; 73 feature-focused tests). The in-memory index remains the default.

Native debug measurement on Moonkale: 8.830 s cold / 0.664 s reopen, including new folder snapshots; store work alone 8.101 s / 0.030 s. 36,704,256 bytes for 478 files / 6,111,526 source bytes. Reopen performs zero parses or replacements (timings rounded independently). The normal form refuses 2,787 definitions and reports 12 ambiguous named bindings; this is partial syntactic coverage. See Indexing for methodology, module-naming limits and evidence. ADR-0029’s release/default gates remain open.

Most important open problems

  1. CI breadth (R-39, WP-26) — default browser smoke suites plus the opt-in structural matrix; startup has a shared 60-minute budget, at most two inactivity-only attempts and retained diagnostics (P-209 CI startup stalls must retain evidence). Several suites remain local-only; three consecutive green runs are still the WP-26 acceptance target.
  2. Security findings — Audit 2026-09-23, Security. #1, #4, #8 fixed in their structural part on refactor (Milestone 18 phase 4.5); the others are open. Don’t expose a server beyond a trusted network.
  3. The core is a library on refactor: moonkale-core, moonkale-ext-api (documented, CHANGELOG.md) and moonkale-graph-render (a Rust API, no Moonkale deps) tagged lib-v1; the shell depends on no extension; no layering exceptions. Workspace is still one large facade — R-37, Milestone 18 - Library Refactor.
  4. Internal state: SQLite chosen (ADR-0014 One store for internal state); layouts, user settings, the entity log and agent sessions are in the store (phase 5); nothing syncs yet — R-36, Internal State.
  5. Release-build observability (P-032): no log file or panic dialog in installed desktop builds (Debugging and Logging).

Sophia history replay (checked 2026-10-24)

ADR-0029 gate 4 now uses reproducible Git-history replay in place of unavailable daily use of the optional folder store. The opt-in tool and hermetic five-commit CI test are implemented. Real Moonkale and Lenticulum histories expose missing and stale live generic names/memberships despite matching file manifests (P-231 Sophia folder replay loses generic memberships). Sophia fixed P-231 in 77f5c1c9, which Moonkale pins by rev; with it both replays are clean (0 differences). The gate counts once that fix is pinned by the v0.1.1 tag. Search stays on the in-memory index (Sophia has no search dialect). The feature remains off by default until gate 3 (wasm or server fallback) is met too. Exact runs and measurements are in Indexing; this checks the replay only, not the older whole-product inventory above.
