Opening several folders at once is intended. A **project** is a saved Moonkale state (not a folder): a set of sources — folders, folders over SSH, GitHub/GitLab/Codeberg repositories, databases, REST APIs — each opened and closed individually, some read-only, each with a colour; a project selector; import/export; synchronisation; and failure notices when a source is missing.

**Documented 2026-09-19** as [[Projects and Sources]] (desired behaviour, project file format, selector, failure report, three sync tiers, what already exists, open questions). Implementation: a milestone of its own — the plan will reference that page; this spec turns `done` when the selector, close/suspend, colours, read-only and the open report work with folders and the existing database files, with the remote/repo/API kinds allowed to follow.
