Once a folder is opened in the explorer I cannot close it.

**Done 2026-09-20.** Three ways: right-click the folder's name in the Explorer → **Close Folder**; *File → Close Folder*; the palette command `workspace.closeFolder` (closes the first folder). `Workspace::close_source(id)` closes the source's documents and the index derived from it; it **refuses while a document of that folder is unsaved** (status: "…: save or reload N unsaved document(s) before closing it") so nothing is lost silently; if it was the folder the workspace settings belong to, the history log is flushed to `.moonkale/history.jsonl` and the presence room left. A new user setting `reopen_last = false` is written on close (and `true` on open), so the next desktop start begins empty instead of reopening the folder that was just closed. Covered by a step in `files.mjs` (refusal while dirty, then close: tree empty, no document tabs, "No folder open"). Per-source close/suspend for the multi-source projects of [[Projects and Sources]] builds on this.
