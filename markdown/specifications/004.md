title: "Spec 004 — Unicode input: \\int → ∫ in every text field"
tags: [spec, editors, input]
status: documented
---
Like the Julia REPL and the Julia/Lean VS Code extensions: an escape (`\`) followed by a name opens a dropdown while typing and Tab/Enter inserts the symbol — `\int` → ∫, `\alpha` → α, `\:ladybug:` → 🐞 — as the default in every text input of Moonkale, with several names per symbol and an editable, extensible table (start from Julia's [unicode-input list](https://docs.julialang.org/en/v1/manual/unicode-input/)).

**Documented 2026-09-19** in [[Unicode Input]]: behaviour (trigger, ranking, Tab/eager acceptance, emoji, cursor templates, undo, reverse lookup), the layered table (built-in Julia + Lean tables, user, workspace, extension; TOML with `names = [...]`, `-name` removals, language scope), where it lives (Rust owns the table; one completion source in CodeMirror, a `UnicodeInput` wrapper for plain inputs, palette command for the terminal), settings — including a per-language escape: LaTeX, Markdown and `.ipynb` use `\` as source, so they default to `;` (or off); Typst does not, renders Unicode directly, and keeps `\` — and the five-step plan. Not implemented.
