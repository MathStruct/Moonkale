The Milkdown extension should have the option to change the font sizes (or fonts in general) — [[Prompt23]].

**Done 2026-09-22.** Three settings under the Markdown extension's row in the Extensions panel (user or workspace scope): **font size** (px, 8–48, default 16), **font** (a CSS `font-family` for the note body; empty = the theme's), **code font** (for code blocks and inline code). They become CSS variables on the rich host (`--mk-rich-size`, `--mk-rich-font`, `--mk-rich-code-font`) that `rich.css` applies to the ProseMirror content; headings scale with the size (Crepe sizes them in `em`). Settings file keys: `editor.rich_font_size`, `editor.rich_font`, `editor.rich_code_font`. Verified in `rich.mjs` (22 px Georgia). Not done: a font picker (type the family), and fonts for the *code* editors (CodeMirror has its own theme; a follow-up).
