It would be good if I can look at the content of png, jpg, svg without leaving Moonkale.

**Done 2026-09-20.** A new optional extension `moonkale-editor-image` ([image.md](https://github.com/MathStruct/Moonkale/blob/master/packages/editors/image/image.md)): clicking a png / jpg / gif / webp / svg / bmp / ico / avif in the Explorer opens a viewer tab — Fit / 100 % / − + zoom (Ctrl+wheel too), drag to pan, dimensions and size in the toolbar, **Source** on SVGs to edit the markup as text. Bytes travel through a new `Source::fetch_bytes` (folder natively; base64 over `/api/sources/fetch_bytes` on the web) into a `data:` URL, so it works on desktop, web and the phone alike; images over 24 MB are refused with a message. Suite `image.mjs` (png opens with `4 × 3`, zoom states, SVG renders and its Source opens in the code editor).
