The code in CodeMirror should have a setting to wrap at the end of the line.

**Done 2026-09-20.** A user setting `editor.wrap` (default off) in `settings.json`; three ways to flip it: the **Wrap** button in every code editor's toolbar (lit when on), **Alt+Z** / palette *View: Toggle Word Wrap* (`editor.toggleWrap`, contributed by the code editor extension), and *Settings → Editor → Wrap long lines*. Every open editor follows the setting live (an effect calls `CodeEditorBackend::set_wrap`; the bundle reconfigures an `EditorView.lineWrapping` compartment), including the markdown source view. Change: `ext-api::settings` (`EditorFile`/`EditorSettings`), `editors/code` (`extension.rs` command, `panel.rs` effect + button, backend `set_wrap`), `js/codemirror` (`setWrap`, `features.wrap`), `ui/settings_panel.rs`. Covered by a step in `highlight.mjs` (button, Alt+Z, persisted in the settings store).
