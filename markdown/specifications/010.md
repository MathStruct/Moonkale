Codemirror does not do syntax highlighting right now for the requested languages.

**Done 2026-09-20** for the languages that have a grammar. Decision **P-093**: highlighting is a *view* concern, so the CodeMirror bundle now carries grammars — the one exception to "no language knowledge in JS" (tree-sitter is native-only; per-keystroke server round trips for highlights would be worse than the rule). Rust still decides the language (`Node::language_hint`, passed as `language` in the `init` message; extended for `.c .h .cc .cpp .hpp .cu .jsx .tsx .nix .cypher .cql .hx .tql .graphql .gql .sh .lua .ipynb`). `packages/js/codemirror/src/languages.ts`: Lezer — Rust, JavaScript/TypeScript (+JSX), C/C++, Go, JSON, Markdown, SQL (SQLite dialect), YAML, Python, CSS, HTML, Typst (`codemirror-lang-typst/lezer`); legacy stream modes — Julia, TOML (Pixi), Cypher, shell, Lua. With a grammar the editor also gets folding (gutter), bracket matching, indent-on-input and **Mod-/** comment toggling. Bundle 368 KB → 1 021 KB. Still plain: Lean 4, Nix, HelixQL, TypeQL, GraphQL (`cm6-graphql` needs the 500 KB `graphql` package — not worth it yet). LSP discovery grew at the same time: clangd, nil/nixd, taplo, tinymist, LanguageServer.jl, JSON/YAML/GraphQL servers. Suite `highlight.mjs`.
