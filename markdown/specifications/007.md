The Android app on my smartphone is currently called "Mobile" and has no Logo. If that is just for the development version then no problem, however I would like the build version to display correct name and Logo.

**Done 2026-09-20.** Cause: dx 0.7.10 labels the Android app after the crate name in PascalCase (`mobile` → "Mobile") and always writes its own template launcher icons into the generated Gradle project; `[application] name` and `[bundle] icon` in `Dioxus.toml` do not reach Android. Fix: `packages/mobile/build-android.sh` runs the dx build, then writes `strings.xml` (`Moonkale`), generates launcher bitmaps for every density plus an adaptive icon (foreground = the picture inset, background = the icon's own backdrop colour) from `assets/icon.png`, removes the template's vector icon, reassembles with Gradle (incremental, seconds) and, with `install`, installs and launches. Renaming the binary would also fix the label but moves the output under `target/dx/moonkale/`, which the desktop crate uses. Verified on the phone: the drawer shows **Moonkale** with the Moonkale icon. The script also clears stale hashed assets first (P-092).
