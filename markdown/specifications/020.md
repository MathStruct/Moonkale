With two folders open, the Graph view drew only the first folder's index. Sometimes one wants the folders in separate graphs, sometimes in the same one — a repository next to the repository it depends on, or two Obsidian vaults about to be merged.

**Done 2026-09-21.** The Graph panel queries **every open folder's index** and draws them in one graph — nodes coloured per folder, with a legend — and the source picker gains one entry per folder (`folder: <name>`) next to "all folders" to narrow the view to a single one; databases and traces stay in the picker as before. Local mode (two hops around the active document) queries every index too and merges the answers. What is *not* there yet: edges **across** folders — a `[[wiki-link]]` in vault A to a page that exists only in vault B stays unresolved (each index resolves within its own folder). Resolving across folders is the "project" idea of [[Projects and Sources]]: one index over several sources, saved as a project. `graph/src/panel.rs` (`indices`, `picked_index`, per-folder colours through `label_color`).
