An extension for Claude Code itself, usable on a Claude subscription without an API key.

**Planned 2026-09-19** in [[Claude Code Extension]]: possible because the `claude` CLI carries the subscription login — Level 1 runs it in the terminal panel (works today), Level 2 makes Moonkale its IDE (lock file + WebSocket MCP server: selection, open file, diffs you accept in Moonkale), Level 3 makes it an agent provider (`claude -p --output-format stream-json …`) with Moonkale's policy gate as its permission prompt and Moonkale's MCP tools (graph, search, databases) available to it. Not implemented.
