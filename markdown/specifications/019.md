The rich markdown editor showed a note's YAML front matter as raw text at the top of the document (`title: …`, `tags: …` between two `---` lines) — Obsidian folds it into a Properties block.

**Done 2026-09-21.** The rich view receives the **body only**; the front matter stays in Rust (`rich.rs`: `split_frontmatter`, `frontmatter_yaml`, `join_frontmatter`) and is shown above the editor as a **Properties** bar — collapsed: `title: … · tags: … · description: …` (first three keys); open: the YAML in a small editor. Edits to the YAML and to the body both go into the same document text, so Save writes `---\n<yaml>\n---\n<body>` exactly; an emptied YAML removes the block; a note without front matter shows "Properties: none" and the bar adds one when filled. The source (CodeMirror) view still shows everything, as it should. Unit test for the split/join round trip; `rich.mjs` step: front matter hidden from the ProseMirror text, summary shown, YAML edited + body edited, file saved intact.
